# Proposal: Clinical Kernel Stage 1 — Characterization and Architecture Gates

## Intent

Etapa 0 froze R1 identity and architecture debt, but several refactor-sensitive properties remain only partially executable. Stage 1 adds a narrow safety net before kernelization: independent behavior characterization and production-only dependency gates, with no functional mutation. The active Etapa 0 overlay remains a separate change.

## Scope

### In Scope

- Create capability `clinical-kernel-stage1-characterization` as a new full OpenSpec capability.
- Close C1 with explicit golden mode/policy context and direct independent-byte comparison.
- Close C2 with exact ordered diagnostic vectors, document nullness, and exit mapping.

No production source, runtime, public API, dependency, config, clinical-semantic, current-main-spec, archive, roadmap, fixture-byte, or Etapa 0 change. This planning batch creates only the four new change artifacts; implementation tests are deferred.
